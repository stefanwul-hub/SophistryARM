# CronoX 3 ARM64 — CRX012

[Télécharger le lanceur CRX012](https://raw.githubusercontent.com/stefanwul-hub/SophistryARM/34154b97eda6a604ea35deb2755c18995d8cc769/CronoX3/Demarrer-CronoX-CRX012.zip).

CRX012 remplace les boucles coûteuses de réverbération du portage générique par leur transcription C++ directe, issue des instructions originales de CronoX 3.6.6. Les filtres en peigne modulés, les diffuseurs et les rendus mono/stéréo gardent leur ordre de calcul float32, leurs arrondis et leurs mémoires. Aucun changement de durée de queue, de release ou de polyphonie.

Le rapport utilisateur RV003 confirme le surcoût : sur Breath And Butter, pendant l’accord, environ 57 % d’un cœur pour ARM contre 11 % pour l’original ; pendant la queue tardive, 43 % contre 3 %. Les voix sont pourtant libérées à 2,07 s et la dernière sortie non nulle se termine au même intervalle (16,875 s). Les chiffres utilisent le temps du processus : le compteur du seul thread Intel est incohérent dans ce rapport et son ratio automatique est écarté. La figure `evidence/cronox-RV003-measured-cpu.png` et son JSON ne contiennent pas le rapport privé.

Quitter Logic et Live, décompacter `Demarrer-CronoX-CRX012.zip`, puis ouvrir `Demarrer-CronoX-CRX012.command`. Le lanceur télécharge les sources épinglées et contrôlées, conserve le projet/cache dans `~/CronoX3-ARM64/projet`, compile en ARM64, vérifie la concordance de la réverbération, les fonctions historiques et l’audio, puis lance `auval -v aumu CrT3 LinP`. Il installe `/Library/Audio/Plug-Ins/Components/CronoX 3 ARM Test.component` après prévalidation et restaure la version ARM Test précédente si une étape échoue. Le rapport ZIP est créé sur le Bureau.

Les 413 unités originales, leur runtime et leur archive restent présents. Seul le petit dispatcher reçoit la sélection des fonctions natives vérifiées ; les états inconnus utilisent le code généré complet. Le test du vrai script sous Bash 3.2 vérifie la réutilisation des anciens objets, la recompilation du seul dispatcher et zéro recompilation d’objet lors d’un second passage inchangé. Les petits hôtes et tests restent reconstruits par l’installeur.

Vérifications de développement : 160 cas, trois blocs chacun, sorties et états complets égaux bit à bit aux instructions i386 originales exécutées sur processeur Intel. Même résultat en ARM64/Linux sous QEMU. Mono, stéréo, buffers partagés, accumulation/remplacement, modulation, bouclages, diffuseurs, nombres faibles et mode FTZ/DAZ sont couverts. Les trois vrais objets de réverbération configurés par le code original acceptent le chemin natif ; le repli est également vérifié. La nouvelle sonde refait les 480 blocs sur le Mac avant installation. Compilation et lien strict Mach-O ARM64 du composant et des sondes réussis ; 28 régressions de transaction/détection et les tests des scripts passent.

**CRX012 n’a pas encore été exécuté sur macOS.** Les tests d’effet isolé établissent la concordance des cas couverts ; ils ne remplacent pas la comparaison d’un preset complet avec l’original. Le gain CPU réel dans Live/Logic reste à mesurer. La charge du reste du synthétiseur, encore élevée dans RV003 sans réverbération, n’est pas corrigée par cette seule traduction. Après installation, comparer Breath And Butter avec le même accord et sa fin de son ; le diagnostic inclut `native_reverb_blocks`, `native_reverb_frames` et les replis.

Identité de comparaison **aumu/CrT3/LinP**, bundle `com.linplug.au.CronoX3.ARMTest`. L’original **CrX3**, ses préférences, **Sophistry CP038**, le gain demandé de +6 dB avant Master et l’interface CRX011 sont conservés. Les identifiants originaux restent réservés à la restauration finale des projets.
