# CP024 — correction de l’affichage et des clics du routage

Le rapport `Sophistry-rapports-CP023-20261116T191207Z.zip` confirme l’installation système CP023/build23001 sous macOS 15.7.2 ARM64, auval réussi, les quatorze cas Cocoa des générateurs et le rappel du nom et du type dans une instance neuve. Les douze WAV reçus ont été comparés indépendamment : ils sont finis et identiques octet par octet dans chaque groupe de référence. Les 32 cas de conversion PCM Apple et les 96 chargements avec mémoire stable passent également. La preuve filtrée est dans [mac-cp023-installed-generators.json](../evidence/mac-cp023-installed-generators.json).

La création d’une vue AU dans un processus séparé et son audio passent. Sa capture de conteneur est entièrement noire ; elle ne certifie pas l’affichage distant et ne permet pas, à elle seule, de conclure que la fenêtre est noire dans Logic ou Live. Les quatorze captures locales montrent bien les générateurs, avec plusieurs défauts graphiques corrigés dans CP024.

## Corrections

- Le nom du type est déjà inscrit dans chaque image de mode. Le texte Cocoa ajouté par-dessus est retiré ; le menu, les clics, l’infobulle et l’accessibilité restent actifs.
- MIX/AM/FM utilise le sprite original `bmp00380.png`, avec ses trois lignes inactives puis ses trois lignes actives. La position est corrigée de `(82,72)` à `(82,86)`, conformément au constructeur original `0x5efe2` et à son appel `0x25926`. L’ancien dessin chevauchait le libellé de balance et laissait un second bouton FM visible.
- Les signes « +/− » dessinés sur les flèches des commandes numériques sont retirés. Les valeurs et les commandes restent actives ; les flèches des images originales sont visibles.

Le moteur, les instructions DSP traduites, les mathématiques, l’allocateur et le convertisseur PCM ne sont pas modifiés. L’identité `aumu/Sop3/LinP`, le bundle `com.linplug.au.Sophistry`, la version de compatibilité 3.0.8, les 522 identifiants AU et le format des chunks restent les mêmes. Le numéro de build est `24001`.

## Installation

Télécharger le lanceur `Demarrer-Sophistry-CP024.command`, fermer Logic et Live, puis exécuter :

```bash
bash "$HOME/Downloads/Demarrer-Sophistry-CP024.command"
```

Il télécharge l’archive immuable vérifiée, l’extrait, compile et exécute les validations. Licence et banque déjà valides sont réutilisées. Le composant précédent est sauvegardé ; une validation échouée entraîne sa restauration. La cible reste `/Library/Audio/Plug-Ins/Components/Sophistry.component`. Attendre « Installation CP024 confirmée ».

Sur une copie de projet, vérifier les panneaux Generators 1–2 et 3–4 : nom de type lisible, boutons MIX/AM/FM alignés et actifs, hauteur et flèches numériques utilisables. Sauvegarder puis réouvrir pour vérifier les réglages et le nom. Le ZIP `Sophistry-rapports-CP024-<date>.zip` contient les résultats et les captures, également en cas d’échec.

CP023 reste la dernière installation confirmée par un rapport Mac. CP024 ne termine pas le navigateur de samples, les zones et boucles détaillées du Loop Sampler, ni les panneaux filtres/effets/modulation. Le trait sombre visible dans la capture du champ de recherche reste à examiner dans les captures d’une fenêtre native ; sa cause n’est pas établie par ce rapport.
