# CP032 — intégrer les blocs manquants du code original

L’utilisateur demande de commencer par la complétude du portage, puis de reprendre le CPU. L’enquête de niveau est mise de côté. Le rapport CP031 confirme installation, auval et huit comparaisons PCM exactes sur les cas testés. Le diagnostic Live montre que l’hôte activait déjà le mode flottant corrigé à CP031 : ce réglage n’explique pas l’écart de CPU observé dans cette session.

## Trois blocs étaient effectivement absents

La nouvelle vérification a retrouvé **huit instructions originales manquantes dans trois blocs**. Des données de tables de saut avaient été désassemblées avec un mauvais alignement, empêchant l’export du début de deux blocs. Une lecture indépendante des tables a ensuite trouvé un troisième bloc.

| Bloc original | Fonction d’origine | Instructions récupérées |
| --- | --- | --- |
| `0x184d4` | `Kaja_c_vslot_244`, entrée `0x18360`, cas 80 | Deux MOV, dont une écriture de l’argument sur la pile |
| `0x23f70` | `Kaja_c_vslot_228`, entrée `0x23e36`, cas 1 | Deux MOV, une addition et une écriture d’argument |
| `0x54534` | `FUN_00054462`, cas 0–3 et 25 | MOV d’une constante et saut vers la suite originale |

Ces instructions proviennent des octets du binaire fourni. Les huit anciennes entrées incorrectement alignées ont été retirées du flux généré. Les données originales des tables restent intactes dans l’image mémoire. Toutes les autres instructions déjà présentes sont inchangées.

L’ancienne version échoue sur le premier nouveau cas avec `fault 3` à `0x184d4`. La version corrigée passe le même test. Il s’agit donc d’une correction de portage reproductible.

## Reproduire l’audit

Depuis la racine du dépôt, avec l’environnement Python d’analyse :

```bash
python scripts/audit_jump_tables.py --output work/audit/switches.json
python scripts/audit_original_code.py --switch-audit work/audit/switches.json --output work/audit/code.json
python scripts/audit_unwind_entries.py --output work/audit/unwind.json
```

La régénération C++ garde la disposition des unités pour permettre la réutilisation des objets inchangés :

```bash
python scripts/lift_pcode_chunks.py analysis/lifter-full/instructions.jsonl.gz src/lifter/whole \
  --reuse-layout src/lifter/whole/manifest.json --update \
  --additions analysis/lifter-full/integration-additions-cp032.jsonl \
  --exclude-addresses analysis/lifter-full/excluded-misaligned-cp032.json
```

Les références nouvelles sont dans `evidence/recovered-code-cp032.fixtures.gz` et leur description dans `evidence/recovered-code-cp032-fixtures.json`. L’installateur vérifie aussi les écritures mémoire du format de fixture SLIP0002.
